# artifacts/ — co-built work products

A shared workspace: slide decks, HTML pages, documents, and other work products you and the agent build together. Any file type. Agents create and edit artifacts here when you direct it. Nothing here is walked, swept, or ingested by the pipeline.

Everything here is readable and linkable — "here is a link to a thing" carries no authorship claim. But authorship inside a co-built file is mixed, so nothing here is citable evidence. If a claim in an artifact matters enough for the wiki, capture it to sources/inbox/ with a speaker — attributed words are what the pipeline can read.

Large binaries snapshot poorly in git and count against Obsidian Sync — exclude this folder from Sync on devices where size matters.

Zone row authority: CLAUDE.md. This README is the folder law that row points agents to read.
