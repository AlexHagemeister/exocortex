# What this folder is

The permanent home for scheduled exports of the user's personal data — calendar, health metrics, and similar. Pre-curated by definition (the user's own data on the user's own schedule), so this stream has no curation gate; modality is the guardrail instead.

# Rules

- **Frozen once filed.** Exports are records of what a system reported at a moment in time.
- [index.md](index.md) is derived; the pipeline regenerates it.

# Evidential modality

- **Calendar entries evidence intention, never occurrence.** "X was scheduled" is supported; "the user did X" requires corroboration from a second stream (a session mention, a note, a health export).
- **Measurements carry error, not ground truth.** A step count or weight reading is an instrument's report — cite it as such, with its date; never round it up to a fact about the world.
