# What this folder is

The permanent home for external sources — articles, papers, posts, documentation — moved here from inbox/ by `ingest`. Filed deliberately by the user (curation is the quality gate for external content; nothing auto-ingests into this stream).

# Rules

- **Frozen once filed.** Never edit or delete a filed source — it is a record of what was said, not a truth claim. A wrong source is outweighed or disputed at the wiki layer, never "fixed" here. <!-- constitution: principle 2, freeze speech -->
- Filenames are permanent: provenance in wiki pages cites these paths forever.
- [index.md](index.md) is derived; the pipeline regenerates it.

# Evidential modality

A filed article evidences **"the author said X"** — never "X is true." Wiki claims built from this stream carry the author's attribution and land as `draft`; truth-status is decided at the wiki layer by status, corroboration, and the user's promotion.
