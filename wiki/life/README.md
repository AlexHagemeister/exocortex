The agent-substrate folder: practical facts about the user's life — health patterns, home, routines, recurring logistics — that let an agent act as a colleague rather than a smart stranger. Fed by the life stream (mind its modality: calendar = intention, measurements carry error) and the notes sweep. **Fast staleness**: life facts rot quickly, so most pages here carry the fast half-life (values live in lint check 2; lifecycle attaches to `type`, never to this folder). Never ships publicly.

**Self-model page law** (`self-model.md` — the Johari ledger): trait- and pattern-level claims about the user only — domain facts stay on their domain pages, and claims link to their evidence rather than restating it (test: the claim would survive the domain becoming irrelevant). The self being modeled is the user; the modelers are both parties — every claim's provenance names whose knowledge it is (self-report / agent inference the user confirmed / a named person's feedback). Nothing enters unadjudicated: content arrives only through an explicit user verdict (the digest's self-interview, or the user's own statement via the pipeline); unconfirmed hypotheses live in digest compiles, never on the page. An **Open questions** section may hold unanswered questions; an **Off limits** section (empty by default — nothing is pre-restricted) lists topics the self-interview never raises, respected the way the notes sweep respects `#no-ingest`.
