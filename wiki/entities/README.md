One page per entity: organizations, places, events, built artworks, named things in the world that aren't people. The test for membership is existence independent of the user: an entity would still be there (or still have been there) if he'd never touched it; his relationship to it is part of the page, not the reason the page exists.

Boundaries with the sibling folders:

- A human goes in `people/`: people are entities, but they have their own folder.
- The user's own ongoing efforts go in `projects/`; when a project engages an entity (a client company, a venue), the engagement page lives in `projects/` and links here.
- Facts about the user himself go in `life/`; biography pages there link out to entity pages rather than absorbing their detail.
- An idea or method goes in `concepts/`: entities are particulars, not generalizable knowledge.

**New-page trigger:** an entity earns a page when filed sources carry claims about it beyond its role in a single project or person page; until then it stays a mention with a red link.

This folder distills notes and sessions about third parties, so like `people/` it never ships in a public bundle without the redaction pass.
