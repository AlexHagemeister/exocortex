# What this folder is

The chronicle records the **user's** days; the sibling log/ records the **pipeline's** acts. Same dates, different books. Each entry distills what the available witnesses (sessions, calendar, reminders, git, meetings, notes) show about how the user spent the day, then says plainly what the agent infers and judges beyond the evidence.

Opt-in feature: adopted via the cookbook recipe `meta/cookbook/chronicle.md` (piloted in the source vault from 2026-08-08, promoted 2026-08-26). Writes happen only through the `chronicle` skill.

# Folder law

- **One page per day**, compiled the following morning. A day runs **04:00 to 04:00** — activity between midnight and 04:00 belongs to the prior day's entry.
- **Naming**: `YYYY-MM-DD-<weekday>.md` (e.g. `2026-08-08-sat.md`); weekly roll-ups `YYYY-MM-DD-week.md` dated by the closing Sunday, which sorts them directly after that Sunday's entry ("week" sorts after every weekday abbreviation, including "wed"). Title and alias carry the human-readable date: "Saturday, August 8, 2026"; "Week of August 3–9, 2026".
- **Five sections, fixed order**:
  1. **Reported** — what the user said they did, quoted or cited from the day's sessions and notes. Highest trust.
  2. **Observed** — mechanical traces: calendar events, Reminders completions, git activity, session existence and duration, meeting records. Records, not claims.
  3. **Inferred shape of the day** — the reconstruction. Every line cites the evidence it extends; an inference resting on a prior entry's inference (rather than evidence) says so inline.
  4. **Coverage** — witnesses consulted, witnesses that returned nothing, witnesses that could not be reached (a failed tool is not an empty record), gaps and uncovered hours. The honest blindness map.
  5. **The agent's read** — the agent's own synthesis and judgment of the day: alignment with stated intentions, patterns, anything the evidence provokes. Explicitly attributed agent judgment, written freely.
- **Entries are living pages** (the user's ruling, 2026-08-08): the compile run writes the first version, but later information is welcome — a newly activated surface, a late-arriving source, the user's own additions. Substantive later material lands as a dated addition ("Added <date>:") so compile-time record and later enrichment stay distinguishable; small factual fixes may edit in place. The user's corrections still flow through the normal corrections path (sources/inbox/) when they change claims, and enrichment writes happen through the chronicle skill or the user's direction in chat.
- **Provenance class**: maintainer-authored observation and inference about the user. Born `draft`, no promotion cycle — an entry is a record, not a claim awaiting verification. Readers weight sections 3 and 5 as draft-grade agent inference, always.
- **Never a citation target**: wiki claims cite the underlying sources these entries themselves cite. Ingest may link chronicle pages but never treats them as evidence of what the user said or did.
- `index.md` here is derived, regenerated by the skill; don't hand-edit.

```yaml
compiled: 2026-08-09

```

Weekly entries use the same shape with `title: "Week of August 3–9, 2026"`. Witnesses consulted are linked inline in the entry's evidence sections, and weekly entries link the seven daily entries in the body. Every entry in this folder follows this shape, including the seventeen written before 2026-08-17: they were migrated to it on 2026-08-18 at the user's direction (link form and citation placement only, no claim changed), so no existing entry is a counter-example to copy from. Quote `description:` when it contains a colon.
