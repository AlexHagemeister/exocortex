# notes/ — the user's own writing

The most write-restricted zone in the vault: every word in a note body is the user's alone. Agents read, link to, and ingest from notes — and never edit, move, rename, or delete one, ever. A note that seems wrong is still the record of what the user wrote; the wiki layer is where claims get weighed.

What agents may write here, exactly:

- **Frontmatter metadata, additive only** — `related:` pointers to existing wiki pages, `description:` when blank and obvious. Never remove or reword a user-authored value. Procedure: the notes sweep in `.claude/skills/process-inbox/` (pass 2).
- **[index.md](index.md)** — the one agent-authored file in this folder; a derived listing, regenerated by the sweep, invisible to it.

`#no-ingest` (inline or in frontmatter tags) is the user's one curation gate: a tagged note is skipped entirely, in both directions — honor it absolutely, and never impose a gate of your own on untagged notes.
